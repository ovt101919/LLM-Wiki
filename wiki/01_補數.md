# 1's 與 2's 補數（Binary Complement）

## 核心概念一句話  
1's 補數是把二進位字串的每一位 0↔1 反轉；2's 補數則在 1's 補數的基礎上再加 1，若產生進位則向左傳遞，最終若仍有進位則在最前端補上 1。

## 詳細原理與規則  

| 步驟 | 說明 |
|------|------|
| **1. 1's 補數** | 逐位遍歷二進位字串，將 `0` 變成 `1`、`1` 變成 `0`。 |
| **2. 2's 補數** | 先取得 1's 補數，然後從最右側（最低位 LSB）開始加 `1`。<br>* 若遇到 `0`，改成 `1` 並停止進位。<br>* 若遇到 `1`，改成 `0`，繼續向左傳遞進位。<br>* 若整個字串都沒有 `0`（全為 `1`），加完後仍保有進位，則在字串最前端插入 `1`。 |
| **3. 輸出** | 同時回傳 1's 補數與 2's 補數兩個結果。 |
| **時間複雜度** | `O(n)`（每個位元最多被訪問兩次：一次求 1's 補數、一次加 1）。 |
| **額外空間** | `O(n)`（需要額外的字串或字符陣列來存放結果）。 |

### 演算法概述（以程式碼流程說明）

1. **求 1's 補數**  
   ```cpp
   for (char &c : s) {
       c = (c == '0') ? '1' : '0';
   }
   ```
2. **求 2's 補數**  
   ```cpp
   bool carry = true;                     // 先加 1
   for (int i = n-1; i >= 0 && carry; i--) {
       if (s[i] == '0') { s[i] = '1'; carry = false; }
       else            { s[i] = '0'; }   // 繼續傳遞 carry
   }
   if (carry) s = '1' + s;               // 全部為 1 時前端補 1
   ```

## 具體計算範例  

### 範例 1  
**輸入** `s = "0111"`  

| 步驟 | 結果 |
|------|------|
| 1's 補數 (翻轉) | `1000` |
| 2's 補數 (在 1000 上加 1) | `1001` |

**說明**  
- 從右側開始加 1：`1000` → 右側 `0` 變 `1`，不再產生進位，結果為 `1001`。

---

### 範例 2  
**輸入** `s = "1100"`  

| 步驟 | 結果 |
|------|------|
| 1's 補數 (翻轉) | `0011` |
| 2's 補數 (在 0011 上加 1) | `0100` |

**說明**  
- `0011` + 1：右側 `1` 變 `0` 並產生進位，下一位 `1` 也變 `0` 再產生進位，最左側的 `0` 變 `1`，停止進位，得到 `0100`。

---

### 範例 3（全 1 的情況）  
**輸入** `s = "1111"`  

| 步驟 | 結果 |
|------|------|
| 1's 補數 | `0000` |
| 2's 補數 | `0001`（加 1 後仍有進位） → 前端補 `1` → `10000` |

**說明**  
- 1's 補數全為 `0`，加 1 後得到 `0001`，但原始長度已無可用的 `0` 供進位，根據規則在最前端插入 `1`，最終結果為 `10000`（比原長度多一位）。

## 常見誤區  

| 誤區 | 說明 | 正確做法 |
|------|------|----------|
| **忘記在 2's 補數加 1 時傳遞進位** | 只把最右側的 `0` 改成 `1`，忽略了連續的 `1` 需要變成 `0` 並向左傳遞。 | 從右至左遍歷，遇到 `1` 時改成 `0` 並繼續，遇到 `0` 時改成 `1` 並停止。 |
| **全 1 時不在最前端補 1** | 以為結果仍是同樣長度的字串，實際上會產生額外的位元。 | 若遍歷完仍有 carry，必須在字串最前端插入 `1`。 |
| **把 1's 補數當成 2's 補數直接使用** | 兩者在數值上相差 1，直接使用會導致錯誤的負數表示。 | 必須先求 1's 補數，再額外加 1 才是正確的 2's 補數。 |
| **把最高位 (MSB) 當作符號位忽略翻轉** | 在純粹的位元翻轉過程中，最高位同樣需要翻轉。 | 1's 補數的翻轉是對整個字串逐位執行，無例外。 |
| **使用十進位思維直接「+1」** | 直接把字串當成十進位加 1 會產生錯誤。 | 必須在二進位層面執行加法，遵循進位規則。 |
